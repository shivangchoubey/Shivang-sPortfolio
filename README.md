## ✦ Getting Started

### Option 1: Instant Local Preview (Zero Config)
You can directly double-click `index.html` in your file explorer to open it in any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Run with Built-in Node.js Server
No dependencies or `npm install` required:
```bash
# Start the server
npm start
# or
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## ✦ Deployment

### Deploy to Vercel
```bash
npx vercel
```

### Deploy to Netlify
Drag and drop this directory into the [Netlify Drop](https://app.netlify.com/drop) dashboard.

### Deploy to GitHub Pages
1. Push to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: portfolio site"
   git remote add origin https://github.com/shivangchoubey/<repo>.git
   git push -u origin main
   ```
2. In Repository Settings → Pages, select `Branch: main`, `Folder: / (root)`, and Save.
